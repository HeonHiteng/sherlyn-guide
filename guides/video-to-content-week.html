Fictional video transcript: A better AI prompt
[00:00–00:20] When an AI answer feels vague, give it a specific task. Instead of “help with content,” ask for three hooks for a 30-second video about study habits.
[00:20–00:40] Give context: who is watching, what they already know, and the tone you want. I might say: university students, first time using AI, friendly and direct.
[00:40–01:00] Define the output: three options, under twelve words each, with no unsupported claims. Then compare the options and edit the one that sounds like you.
[01:00–01:20] Before posting, check facts and remove anything you cannot support. AI drafts save a starting step, but you still own the final words.

2. Run the prompt

Send this in the same chat after the source. It specifies both the output and how to handle missing information.

Turn this transcript into a five-day content pack. Produce: two clip ideas with exact source time ranges and draft captions under 40 words; one four-slide carousel with actual slide copy; one audience question; one checklist post. Label adaptations as new copy, not verbatim quotes. Link each asset to its source time range. Do not invent results, statistics or footage. Do not claim to have edited video. Include a final fact-check list.

3. Check the result

All timestamps must be inside 00:00–01:20. The example contains no performance statistics, so neither should the output. Carousel copy should be ready to edit, not just a list of vague slide ideas.

If it fails, point to the exact source line and ask for a corrected result. Check again; do not accept a confident explanation instead of matching evidence.

4. Use it for your own work

For your own video, export its transcript with timestamps, then run the prompt. Open the original video in your editor and trim the suggested ranges; adjust cuts at sentence boundaries. Add captions and review them against the audio. This workflow makes a plan and copy, not rendered video files.

If your result looks wrong

Start a fresh chat with only the intended source and prompt. For missing output, ask the AI to return plain text or a CSV code block you can save yourself. For large files, process labelled batches and reconcile IDs and counts before combining. Remove private details you do not need before using your own data.

Optional upload help: Google’s file attachment instructions. Pasting the small practice input works without file-upload features.
