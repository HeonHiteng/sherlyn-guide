Turn customer feedback into a priority list

Count unique reports, preserve evidence and separate frequency from impact.

What you need: an AI chat tool that accepts pasted text, plus a text editor or spreadsheet. Allow 20–40 minutes. No API or paid automation required; your chat tool’s usage limits apply.

2. Run the prompt

Send this in the same chat after the source. It specifies both the output and how to handle missing information.

Group the attached feedback into actionable themes. Count unique customers per theme, not messages. Preserve feedback IDs and one exact supporting quote for each theme. Separate positive feedback from requests and problems. Prioritise using observed impact and frequency; label impact judgements as interpretation. Do not invent revenue loss or imply this sample represents all customers. Return a compact table and one validation question per problem theme.

3. Check the result

Checkout has three messages but only two unique customers. Invoice discovery also has two customers. The higher checkout priority comes from possible blocking impact, not a larger count. No revenue-loss figure can be inferred.

If it fails, point to the exact source line and ask for a corrected result. Check again; do not accept a confident explanation instead of matching evidence.

4. Use it for your own work

Paste the reviewed table into your planning document. Include the original IDs so teammates can inspect the evidence. Reproduce the checkout issue before assigning a fix; ask invoice respondents where they expected the link. Repeat with a new batch and use stable customer IDs to avoid double-counting.

If your result looks wrong

Start a fresh chat with only the intended source and prompt. For missing output, ask the AI to return plain text or a CSV code block you can save yourself. For large files, process labelled batches and reconcile IDs and counts before combining. Remove private details you do not need before using your own data.

Optional upload help: Google’s file attachment instructions. Pasting the small practice input works without file-upload features.
