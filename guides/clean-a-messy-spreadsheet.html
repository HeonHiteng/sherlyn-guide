Clean a messy spreadsheet with AI

Standardise safe fields, isolate ambiguous dates and keep a change log.

What you need: an AI chat tool that accepts pasted text, plus a text editor or spreadsheet. Allow 20–40 minutes. No API or paid automation required; your chat tool’s usage limits apply.

2. Run the prompt

Send this in the same chat after the source. It specifies both the output and how to handle missing information.

Clean this CSV without overwriting the original. Preserve row_id, order_id strings and leading zeros. Trim name whitespace and uppercase currency. The date locale is unknown: do not guess 03/04/2026. Do not replace missing amounts with zero. Identify duplicates only after safe whitespace/currency normalisation; keep the earliest row and log which row was removed. Produce cleaned.csv, exceptions.csv and changes.csv as separate CSV code blocks. Keep every unique unresolved row in cleaned.csv with a review status. Explain the input/output row counts.

3. Check the result

Five input rows must become four retained rows plus one logged duplicate. Only r3 and r4 need review. Known retained amounts sum to 200, not 320. This is not a complete total because r4 is missing. Order IDs must retain leading zeros.

If it fails, point to the exact source line and ask for a corrected result. Check again; do not accept a confident explanation instead of matching evidence.

4. Use it for your own work

Save each CSV code block as a UTF-8 .csv file. Import into a new spreadsheet with automatic text-to-number/date conversion disabled where available, so 001 stays 001. Verify row counts and the change log before replacing a working dataset. Ask the source owner to resolve r3’s date and r4’s missing amount.

If your result looks wrong

Start a fresh chat with only the intended source and prompt. For missing output, ask the AI to return plain text or a CSV code block you can save yourself. For large files, process labelled batches and reconcile IDs and counts before combining. Remove private details you do not need before using your own data.

Optional upload help: Google’s file attachment instructions. Pasting the small practice input works without file-upload features.
