Give your AI agents a 3D office

Hermes3D turns your Hermes agents into little characters in a 3D office. See who’s working, who’s idle, and what’s on their Kanban board. It’s free and open source.

ToolHermes3D (free, open source)
SetupOn your own computer
TimeAbout 10 minutes

Repo: Hermes3D on GitHub, built by @iamlukethedev.

Jump to a section 1 · What you need 2 · Let Claude do it 3 · Make a token 4 · Start Hermes 5 · Start Hermes3D 6 · Connect 7 · Troubleshooting

What you need

  • Hermes Agent installed and working. If hermes runs in your terminal, you’re good.
  • Node.js 20 or newer.
  • Git.
The commands below use Bash: Terminal on macOS or Linux, or WSL on Windows. You’ll also need openssl to generate the token.

The easy way: let Claude do it

Open Claude Code and paste this:

Set up Hermes3D for me from https://github.com/iamlukethedev/Hermes3D. I already have hermes-agent installed on this machine. Follow docs/hermes-agent-tailscale.md, but everything runs locally, so skip the Tailscale parts. Save a token as HERMES3D_OFFICE_TOKEN in ~/.hermes/.env, start hermes serve on 127.0.0.1 port 9120, start Hermes3D, then tell me exactly what to type into the connect screen.

Claude handles the rest. If you’d rather do it yourself, here are the four steps.

1. Make a token (once)

This is the password between Hermes and the office.

echo "HERMES3D_OFFICE_TOKEN=$(openssl rand -hex 32)" >> ~/.hermes/.env

Run this only once. If you already have HERMES3D_OFFICE_TOKEN in that file, reuse it instead of adding a second entry.

2. Start Hermes for the office

HERMES_DASHBOARD_SESSION_TOKEN="$(grep '^HERMES3D_OFFICE_TOKEN=' ~/.hermes/.env | cut -d= -f2)" hermes serve --host 127.0.0.1 --port 9120 --skip-build
Leave this terminal open. Close it and the office goes offline.

3. Install and start Hermes3D

In a new terminal:

git clone https://github.com/iamlukethedev/Hermes3D.git
cd Hermes3D
npm install
cp .env.example .env
npm run dev

Keep this terminal open too.

4. Connect

Open http://localhost:3000 and fill in the connect screen:

FieldWhat to put
BackendHermes Agent (direct)
Gateway URLws://localhost:9120
Gateway TokenRun grep '^HERMES3D_OFFICE_TOKEN=' ~/.hermes/.env and paste everything after the =.

Hit Connect. Each Hermes profile shows up as its own character, and the Kanban board works straight away.

If it doesn’t work

  • Connects, then drops with a 403: the token doesn’t match. Copy it again from ~/.hermes/.env.
  • Won’t connect at all: check that both terminals are still running. If the Hermes terminal closed, run the step 2 command again.
  • Only one character: you have one Hermes profile. One profile = one agent in the office.
Two don’ts:
  • Don’t save HERMES_DASHBOARD_SESSION_TOKEN in ~/.hermes/.env. It breaks the Hermes desktop app. Use the HERMES3D_OFFICE_TOKEN name from step 1.
  • Don’t share your token. Anyone with it can talk to your agents.

Hermes running on another machine, like a Mac mini or a server? Follow docs/hermes-agent-tailscale.md in the repo. If you serve a specific profile, use that profile’s HERMES_HOME for its .env file.
